1. What happens to the test stars?

A new installation starts with 0 stars. There is no test balance bundled into the website files. Test activity lives in the browser where you tried the preview; it does not automatically move from your Mac to the iPad.

Keep changes you made while testing

Custom missions, rewards, prices, pins and photo-album entries made inside your Mac preview are also saved in that browser. To bring them across, open your original Round 7 preview and choose room name → Bedtime tidy-up → Backups → Export backup. Save the JSON file to iCloud Drive or another private location accessible from the iPad.

After completing the installation below, open the app from its Home Screen icon. Go to the same Backups page, choose Restore a backup and select that JSON. Then choose Clear test progress, type START and confirm.

The reset keeps all mission/reward definitions, settings, pins and photos. It clears test stars earned and spent, mission completions, reward-use history and cooldown use, weekly progress, and found cats. It also clears test wardrobe spending while retaining owned outfits. Dated one-off definitions keep their original date. A pre-reset record snapshot is kept locally for recovery; this is not an external backup.

Also clear the Mac testing copy

Open Mac - clear test progress.html in the same normal browser you used for testing. Use room name → Bedtime tidy-up → Backups → Clear test progress. Type START and confirm. Nothing is wiped just by opening this helper.

Some browsers keep local HTML files in separate storage areas. If the helper cannot see your old custom content, leave the original preview alone, export its backup and restore it into the helper before clearing. Your old Mac file is not remotely edited by this package. Do not clear all browser data as a shortcut.

2. Give the app a private website address

The recommended route is Netlify’s folder upload. Use your own account.

Open Netlify dashboard
  1. Sign in. Before uploading, choose Team settings → General → Visitor access → Default project visibility → Private for new projects.
  2. Open Netlify Drop while signed in. Drag only this package’s website folder into the upload area.
  3. Keep production and previews Private. Copy the main site address Netlify gives you, not a version-specific preview address.

Private projects on current credit-based Free/Personal plans use the owner’s Netlify login. Authorize the family iPad yourself; no child account is needed. Shared-password protection requires Pro. A private deployment may show a Netlify banner. Labels can differ on legacy plans. Visibility guide · Upload guide · Password options

Keep it private. The website contains Alba’s name and drawings of your home. A difficult-to-guess address or a “noindex” tag is not access protection. The host login protects access to the website; the removed parent lock has not been put back inside the app. Do not share your login or any backup file publicly.

3. Add it to the iPad Home Screen

  1. On the iPad, open the main website address in Safari while connected to Wi-Fi. Complete the host sign-in yourself.
  2. Tap Share (the square with an upward arrow), then Add to Home Screen. It may be under More.
  3. Turn on Open as Web App if that option is shown. Name it Fairy Stars, then tap Add.
  4. Open the new icon while still online. Sign in again if requested.

Apple’s Home Screen instructions. On earlier iPadOS releases the “Open as Web App” switch may not be displayed.

Do not try to install the downloaded Mac HTML preview from the Files app. This build uses a hosted HTTPS page plus an offline cache, rather than a native App Store installation.

4. Start clean, then keep the stars safe

In the installed app, open room name → Bedtime tidy-up → Backups. Wait for Offline ready. This means the installation has cached the app and its artwork. Keep Wi-Fi on until that message appears.

Complete any backup restore and test-progress reset from step 1. Check the counter reads 0. Export a fresh backup after this clean start.

For one installation check, turn Wi-Fi off and reopen the Home Screen icon. Visit a few rooms and confirm the animated character loads, then turn Wi-Fi back on. No test mission needs to be completed. If it does not reopen offline, return online and check the installation status before using it for real saved progress.

From then on, use the Home Screen icon. Save a full backup weekly: Backups → Export backup → Share / Save to Files, and choose a private iCloud Drive folder. Confirm “I have saved a copy” only after saving it.

Avoid clearing website data or deleting/reinstalling the app without a backup. The website host serves the app; it is not a backup of your star balance or photos. Local snapshots are useful, but can be lost with browser storage. Keep the same website address for later app updates.

Why do the stars on my Mac and iPad differ?

Each browser/device keeps its own progress. The app has no automatic sync. A backup export and restore is the explicit transfer method. Restoring replaces the target device’s current records, so save its backup first when it already has progress worth keeping.
